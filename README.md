# Жалағаш өлкетану картасы

«Жалағаш өңіріндегі ұмыт қалған тарихи орындар мен сакралды нысандарды зерттеу, цифрландыру және туристік айналымға енгізу» ғылыми жобасының цифрлық бөлігі.

- **Сайт:** https://skakovizbasar5-alt.github.io/zhalagashkoneoryndar/
- `qorgau.html` — жобаны қорғауға арналған презентация-бет
- `index.html` — 3D өлкетану картасы (4 нысан, маршрут, дәуірлер, сауалнама)
- `cards/` — QR сканерлегенде ашылатын нысан карточкалары (ҚАЗ / РУС / ENG, 3D модель)
- `qr/` — басып шығаруға арналған QR-тақтайшалар және A4 парақ
- `info/` — карточкалардың сурет нұсқасы

| Шифр | Нысан | Карточка |
|---|---|---|
| ЖЛ-01 | Шірік-Рабат төбелері маңайындағы сақ обалары | cards/shirik.html |
| ЖЛ-02 | Мөпше төбе қонысы | cards/mopshe.html |
| ЖЛ-03 | Ескі Күшікбай қорымы мен мазары | cards/kushikbai.html |
| ЖЛ-04 | Қалқай ишан кесенесі мен медресе орны | cards/kalkai.html |
